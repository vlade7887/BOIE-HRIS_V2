# BOIE HRIS
# Employee Module Specification v1.0

---

# Purpose

The Employee Module is the central module of the BOIE HRIS.

All modules including Attendance, Leave, Payroll, Reports and Employee 201 File are linked to Employee.

---

# Employee Number

Format

224-1004

Employee Number is permanent.

Never reuse employee numbers.

# Rules

Employee Number cannot be changed.

Deleted employees are Soft Deleted only.

All changes must be recorded in Assignment History.

Employee records are never permanently deleted.
